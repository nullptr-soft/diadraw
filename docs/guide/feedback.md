# Reporting bugs and giving feedback

Every DiaDraw app has a **Give Feedback** button in its toolbar, always in sight: one click opens
the feedback form, for ideas, wishes, or anything that could be easier. **Report a Bug…** is for
when something does not work the way it should.

| App                     | Give Feedback                    | Report a Bug                        |
| ----------------------- | -------------------------------- | ----------------------------------- |
| macOS                   | right end of the toolbar         | Help menu                           |
| Linux (GTK)             | header bar, beside the main menu | the main menu (☰) at the top right |
| Windows                 | right end of the toolbar         | Help menu                           |
| Web and desktop (Tauri) | right end of the toolbar         | beside Give feedback                |

The website has Give feedback at the top of every page too.

Each opens a new issue on DiaDraw's GitHub tracker in your browser, with the app, the DiaDraw
version and your system already filled in. You need a GitHub account to send it. Nothing leaves
the app until you press **Create** on GitHub, and your diagram is never attached: if the problem
depends on the diagram, paste the smallest `.draw` text that shows it into the form, leaving out
anything you would not want to share.
