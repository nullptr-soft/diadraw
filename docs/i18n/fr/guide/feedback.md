# Signaler un bogue et donner son avis

Dans chaque application DiaDraw, le bouton **Give Feedback** est toujours visible dans la barre d’outils. Un clic ouvre le formulaire où proposer une idée, formuler un souhait ou signaler une manipulation qui pourrait être plus simple. Utilisez **Report a Bug…** lorsqu’une fonctionnalité ne marche pas comme prévu.

| Application | Give Feedback | Report a Bug |
| --- | --- | --- |
| macOS | à droite de la barre d’outils | menu Aide |
| Linux (GTK) | barre d’en-tête, à côté du menu principal | menu principal (☰), en haut à droite |
| Windows | à droite de la barre d’outils | menu Aide |
| Web et bureau (Tauri) | à droite de la barre d’outils | à côté de Give Feedback |

Le site propose aussi un lien pour donner votre avis en haut de chaque page.

Chaque commande ouvre dans votre navigateur un nouveau ticket sur GitHub pour DiaDraw ; le nom de l’application, la version de DiaDraw et votre système sont préremplis. Un compte GitHub est nécessaire pour envoyer le ticket. Rien ne quitte l’application tant que vous n’avez pas cliqué sur **Create** sur GitHub, et votre diagramme n’est jamais joint. Si le problème dépend du diagramme, collez dans le formulaire le plus petit extrait `.draw` qui le reproduit, sans rien inclure que vous ne souhaitiez partager.
