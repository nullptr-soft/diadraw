# Fehler melden und Feedback geben

Jede DiaDraw-App hat eine stets sichtbare Schaltfläche **Give Feedback** in der Symbolleiste. Ein Klick öffnet das Feedbackformular für Ideen, Wünsche oder Dinge, die einfacher sein könnten. **Report a Bug…** ist für Fälle gedacht, in denen etwas nicht wie erwartet funktioniert.

| App | Give Feedback | Report a Bug |
| --- | --- | --- |
| macOS | rechts in der Symbolleiste | im Hilfemenü |
| Linux (GTK) | in der Kopfleiste neben dem Hauptmenü | im Hauptmenü (☰) oben rechts |
| Windows | rechts in der Symbolleiste | im Hilfemenü |
| Web und Desktop (Tauri) | rechts in der Symbolleiste | neben Give Feedback |

Auch auf der Website findest du oben auf jeder Seite einen Link, um Feedback zu geben.

Beide Schaltflächen öffnen im Browser ein neues Issue im GitHub-Tracker von DiaDraw. App, DiaDraw-Version und Betriebssystem sind bereits eingetragen. Zum Absenden brauchst du ein GitHub-Konto. Erst wenn du auf GitHub auf **Create** klickst, werden Daten übermittelt. Dein Diagramm wird nie angehängt. Hängt der Fehler vom Diagramm ab, füge den kürzesten `.draw`-Text, mit dem er auftritt, ins Formular ein. Lass alles weg, was du nicht teilen möchtest.
