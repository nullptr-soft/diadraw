# Переміщення блоків

Перетягніть блок, щоб його перемістити. У будь-якому поданні незалежно від компонування він залишиться там, де ви його відпустили. Коли ви відпускаєте блок, до подання записується один рядок:

```
view main {
  include *
  layout layered direction down
  pin db at 262, 246
}
```

Як і `size` чи `rotate`, цей рядок належить лише цьому поданню, тому той самий елемент може бути в різних місцях у різних поданнях. За автоматичного компонування решту блоків і далі розміщує алгоритм: якщо переміщений блок накладається на інший блок, той відсувається, а маршрути дотичних ліній перебудовуються. Перетягніть блок ще раз, і його рядок `pin … at` оновиться відповідно до нової позиції.

## Розміщення відносно сусідів

Утримуйте Option (Alt у Windows і Linux) під час перетягування, щоб розмістити блок відносно інших. Поки ви його тягнете, над ним відображається рядок, який буде записано:

- Якщо блок вирівнюється з іншим із допуском у 14 пікселів, перетягування записує `align api db horizontally` (або `vertically`).
- Інакше записується `pin db right of api` (або `left of`, `above`, `below`) відносно найближчого блока.

Ці рядки зберігають свій зміст при зміні компонування, тому зручні для діаграм, що зростають. Якщо умова вже виконується, наприклад два блоки вже стоять в одному ряду, блок залишається там, де його розмістив алгоритм.

У поданні `layout fixed` перетягування завжди записує `pin … at`, з Option чи без. Див. [Малювання вручну у фіксованих поданнях](fixed-views.md).

## Вибір і переміщення кількох блоків

Клацніть блок, щоб вибрати його. Клацання з Shift (або з Command у macOS, Ctrl у Windows і Linux) додає блок чи лінію до вибраних об’єктів або вилучає їх із вибору. Щоб виділити ділянку, натисніть на порожньому місці полотна й розтягніть рамку: буде вибрано всі блоки та лінії, які повністю в неї потрапили (утримуйте Shift чи Command/Ctrl, щоб додати їх до вже вибраних). На полотні Command-A (Ctrl-A у застосунку Linux і вебзастосунку у Windows і Linux) вибирає все подання, а Escape чи клацання порожнього полотна скидає вибір. Якщо клацнути один із кількох вибраних блоків без перетягування, лише він залишиться вибраним.

Перетягніть будь-який із вибраних блоків — вони перемістяться разом, зберігаючи взаємне розташування. Контур кожного з них показує його майбутнє місце. Коли ви відпустите блоки, для кожного буде записано рядок `pin … at`, але це одна зміна: одне скасування поверне їх усі назад.

```
view main {
  include *
  layout layered direction down
  pin api at 262, 120
  pin db at 262, 246
}
```

Група завжди залишається там, де ви її відпустили: Option (Alt) не розміщує її відносно сусідів. У поданні `layout fixed` лінія, обидва кінці якої рухаються, зберігає форму, бо точки згину переміщуються разом із нею. Delete (або Backspace) видаляє всі вибрані об’єкти.

Натискання всередині контейнера вибирає сам контейнер замість розтягування рамки. Тому починайте рамку поза ним або вибирайте його блоки клацанням із Shift.

## Як повернути блок на місце

Видаліть із подання його рядок `pin`, `align` або `order`, і алгоритм знову розмістить блок самостійно.
