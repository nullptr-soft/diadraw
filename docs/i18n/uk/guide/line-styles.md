# Закінчення та стилі ліній

Стрілка зв’язку (`->`, `-->`, `<->`) задає звичайний вигляд: суцільну або штрихову лінію із заповненим наконечником. Коли діаграма дотримується певної нотації, як-от UML, модель «сутність — зв’язок» або схема потоків даних, і закінчення, і сама лінія мають значення. Виберіть їх за допомогою стилю для окремого зв’язку або всіх ліній із певним тегом.

## Вибір у застосунку

Виберіть лінію. У розділі **Style** панелі властивостей є окремі засоби для кожного параметра:

- **Start** та **End** вибирають закінчення. У macOS і Linux біля кожного варіанта видно мініатюру лінії. У macOS і вебзастосунку варіанти об’єднано в групи Arrows, Shapes, Lines і Crow’s foot.
- Якщо зняти позначку **Filled start** або **Filled end**, відповідний трикутник, півстрілка, ромб, коло чи квадрат буде порожнистим.
- **Line style** вибирає, як малювати лінію: суцільною, штриховою, з крапок, з коротких або довгих штрихів, штрих і крапка чи штрих і дві крапки. На macOS і Linux кожен пункт показує невеликий зразок лінії.
- **Double line** малює дві тонкі лінії замість однієї; **Line width** збільшує товщину лінії.
- **Routing** прокладає лінію під прямими кутами, **Curved** плавно проводить її через точки згину, а **Rounded corners** заокруглює кути.

Кожна з цих дій записує один ключ у `style "…"` зв’язку й залишає решту тексту без змін. Повернення параметра до типового значення видаляє його ключ.

## Запис у тексті

Ті самі ключі записуються в `style "key=value;…"` після зв’язку:

```
model {
  customer = process "Customer"
  order = process "Order"
  customer -> order "places" style "startArrow=ERmandOne;endArrow=ERzeroToMany"
  order -> customer "notifies" style "dashed=1;dashPattern=1 3;endArrow=open;curved=1"
}
```

Щоб оформити всі лінії з певним тегом, використовуйте блок стилю (див. [Стилі й теми](styles-and-themes.md)):

```
style relationship tag "async" { dashed true dashPattern "1 3" endArrow open }
```

### Закінчення

`startArrow` і `endArrow` приймають наведені нижче значення. Це назви з draw.io, тому імпортована з draw.io діаграма зберігає свої закінчення.

| Значення | Вигляд | Типове використання |
| --- | --- | --- |
| `classic` | стрілка | виклик або залежність (типове закінчення) |
| `block` | трикутник | успадкування UML (порожнистий, `endFill=0`) |
| `open` | відкрита стрілка | залежність UML, повідомлення |
| `async`, `openAsync` | півстрілка, відкрита півстрілка | асинхронне повідомлення |
| `doubleBlock` | подвійний трикутник | швидкий або пріоритетний потік |
| `diamond` | ромб | композиція UML (заповнений), агрегація (порожнистий) |
| `oval` | коло | точка з’єднання |
| `box` | квадрат | порт або кваліфікатор |
| `circlePlus` | коло з плюсом | вкладення UML |
| `halfCircle` | гніздо | потрібний інтерфейс |
| `baseDash`, `dash`, `cross` | риска, скісна риска, хрестик | зупинка, розрив, заборонений потік |
| `ERone`, `ERmandOne`, `ERzeroToOne` | «вороняча лапка»: один | один, рівно один, нуль або один |
| `ERmany`, `ERoneToMany`, `ERzeroToMany` | «вороняча лапка»: багато | багато, один або багато, нуль або багато |
| `none` | нічого | ненапрямлена лінія |

Без `startArrow` лінія не має початкового наконечника, якщо тільки не записана через `<->`. Без `endArrow` вона закінчується стрілкою. `startFill=0` і `endFill=0` роблять фігури порожнистими.

### Лінія

| Ключ | Дія |
| --- | --- |
| `dashed=1` | робить лінію штриховою (як `-->`) |
| `dashPattern=…` | візерунок: `1 3` — крапки, `3 3` — короткі штрихи, `12 6` — довгі, `8 3 1 3` — штрих і крапка |
| `double=1` | дві лінії з тлом між ними |
| `strokeWidth=…` | товщина, типово 1,25 |
| `stroke=#…` | колір |
| `edgeStyle=orthogonalEdgeStyle` | прокладання під прямими кутами |
| `curved=1` | плавні криві через точки згину |
| `rounded=1` | заокруглені кути |

`dashPattern` видно лише на штриховій лінії; параметр Line style у застосунку задає обидва ключі.

## Корисно знати

- Пряма лінія не має кутів, тому `curved` та `rounded` її не змінюють. Ефект видно, коли лінія згинається: у компонуванні, яке обходить блоки, на прямокутному маршруті або вздовж точок згину `route`.
- Проміжок у подвійній лінії малюється кольором тла сторінки. Коли подвійна лінія перетинає групу чи контейнер із заливкою, у проміжку видно колір сторінки.
- Під час експорту в draw.io закінчення, `dashPattern`, `curved` і `rounded` зберігаються з лінією; `double` — ні, бо draw.io малює подвійні лінії як інший тип ребра.
- Під час імпорту з draw.io закінчення переносяться, але криві ребра, заокруглення кутів і візерунок штрихів поки що ні, тому імпортовані сторінки виглядають так само, як до додавання цієї функції.
