# Стилі та теми на полотні

Вигляд діаграми задається на трьох рівнях. **Тема** визначає загальні кольори та шрифти. **Блоки стилів** надають спільного вигляду всім елементам певного виду, усім об’єктам із тегом або всім зв’язкам. Власний **вбудований стиль** елемента (поле Style в [інспекторі](element-properties.md)) змінює лише цей елемент. У тексті це виглядає так:

```
theme brand extends dark {
  background "#101418"
  node person { fill "#08427b" stroke "#052e56" text "#ffffff" }
}

theme brand

style container {
  fill "#438dd5"
}
style tag "external" { fill "#999999" dashed true }
style relationship tag "async" { dashed true }
```

У [довіднику DSL](../dsl.md#стилі-й-теми) наведено всі селектори та ключі. Цей розділ пояснює, як змінювати їх із полотна: усе можна редагувати, не залишаючи діаграму, і кожна зміна все одно потрапляє в текст.

## Що й коли використовувати

- Використовуйте **блок стилю**, якщо вигляд стосується виду або тегу: «кожна база даних помаранчева», «усе з тегом `external` сіре та зі штриховим контуром». Нові елементи цього виду або з таким тегом отримають стиль автоматично.
- Використовуйте власне поле **Style** елемента, якщо саме він має відрізнятися від інших.
- Використовуйте **тему** для всієї діаграми: тла, кольору ліній, шрифту та типових кольорів кожного виду. Виберіть вбудовану (`default`, `dark`, для друку — `mono`) чи створіть власну.

Коли діють кілька правил, конкретніше має перевагу. Порядок від загального до конкретного: тема, блоки `*`, блоки виду, блоки тегу, блоки виду й тегу, а насамкінець — власний стиль елемента.

## Спільні стилі елемента

Виберіть один елемент, і внизу інспектора з’явиться поле **Shared styles**. У ньому перелічено блоки стилів, які діють на елемент, по одному на рядок у порядку їх запису:

```
container: fill=#438dd5
tag "external": fill=#999999;dashed=1
```

Кожен рядок складається із селектора, двокрапки й ключів у форматі поля Style (пари `key=value`, розділені `;`). Редагування поля змінює блоки:

| Ваша дія | Зміна в тексті |
| --- | --- |
| змінити значення | відповідний рядок блока переписується |
| додати ключ до рядка | ключ додається в кінець блока |
| видалити ключ | його рядок у блоці видаляється |
| додати рядок, наприклад `database: fill=red` | після показаних блоків з’являється новий блок `style` |
| видалити рядок | блок цього рядка видаляється |
| змінити селектор рядка | селектор блока змінюється, а тіло залишається |

Зміна в цьому полі змінює вигляд **кожного** елемента, до якого застосовується блок, а не лише вибраного. Саме для цього воно призначене. Щоб змінити лише поточний елемент, скористайтеся його полем Style.

Поле приймає лише селектори, застосовні до вибраного елемента: його вид, його теги, вид разом з одним із тегів або `*`. Рядок для іншого виду чи для зв’язків відхиляється з повідомленням у рядку стану. Щоб редагувати такі блоки, скиньте вибір (див. нижче).

## Тема й стилі документа

Клацніть порожню ділянку полотна. Коли нічого не вибрано, панель властивостей біля полотна показує параметри документа:

- **Theme**: інструкція `theme` документа. Введіть `default`, `dark`, `mono`, оголошену вами тему чи бібліотечну тему (`acme.corporate`). Очищення поля видаляє інструкцію.
- **This view's theme**: `theme` всередині поточного подання, яка має перевагу над темою документа лише в цьому поданні. Порожнє поле означає, що подання використовує тему документа.
- **Style blocks**: усі блоки стилів документа, включно з блоками зв’язків, наприклад `relationship tag "async": dashed=1`, по одному на рядок, як описано вище.

### Створення власної теми

У поле Theme (або This view's theme) введіть нове ім’я теми, наприклад `night`. DiaDraw оголосить її на основі теми, яку вона замінює, і вибере її:

```
theme night extends dark {}

theme night
```

Якщо подання малюється з темою, оголошеною в документі, панель показує її розділ, **Theme night**, із трьома додатковими полями:

- **Extends**: тема, від якої вона успадковує властивості. Порожнє значення означає `default`.
- **Theme keys**: по одній парі `key=value` на рядок: `background`, `fontFamily`, `fontSize`, `edge`, `edgeText`, `boundary` та інші ключі з [довідника DSL](../dsl.md#власні-теми).
- **Node colours**: один вид на рядок із його `fill`, `stroke` і `text`: `person: fill=#08427b;stroke=#052e56;text=#ffffff`. `default` означає всі види без власного рядка, `external` — усі елементи з тегом `external`. Для людини `text` задає колір імені лише тоді, коли `shape` малює її як заповнений блок; підпис схематичної фігурки людини розміщується на полотні й має колір `labelText`.

Вбудовані й бібліотечні теми не можна редагувати на місці; створіть власну тему на їх основі.

### У застосунках для macOS, вебу та Linux

Застосунки показують ці поля як елементи керування, які записують той самий текст:

- **Theme**, **This view's theme** і **Extends** — розкривні списки із вбудованими темами, темами ваших бібліотек і темами, оголошеними в документі. Можна й увести нове ім’я.
- **Style blocks** — список з одним рядком на блок. Виберіть чи введіть селектор (`*`, `relationship`, вид, `tag "external"`, `relationship tag "async"`). Розгорніть рядок трикутником, щоб змінити ключі в такому самому редакторі стилів, як в інспекторі елемента; видалити рядок можна кнопкою −. **Add style block** додає рядок.
- **Theme keys** має кнопку кольору для кожного колірного ключа (`background`, `edge`, `boundary` тощо) і текстові поля для `fontFamily` та розмірів шрифту. Кнопки кольорів пропонують ту саму готову палітру, що й інспектор елемента, з Custom… для довільного кольору. Кнопка × біля кольору видаляє ключ, тож тема повертається до успадкованого значення. Не показані на панелі ключі зберігаються.
- **Node colours** має рядок для кожного виду з кнопками кольорів Fill, Line і Text. Для нового рядка виберіть вид і натисніть Add; рядок буде записано, щойно в ньому з’явиться колір.

У вебзастосунку поля тем підказують вбудовані та оголошені в документі теми, а трикутник блока стилю згортає його до короткого однорядкового переліку ключів.

У застосунку Linux (GTK) Theme, This view's theme та Extends — поля з кнопкою ▾ для списку тем, Style blocks — список блоків із кнопкою ▸ для відкриття редактора стилів, а Theme keys і Node colours використовують кнопки кольору.

## Застосування зміни

Поля працюють як в інспекторі елемента: зміна застосовується, коли ви натискаєте Enter чи виходите з поля після редагування, а Escape повертає попереднє значення. Багаторядкові поля (Shared styles, Style blocks, Theme keys, Node colours) застосовуються при виході з них або за ⌘Enter / Ctrl+Enter у вебзастосунку. У застосунку macOS Return застосовує Shared styles, а ⌥Return починає новий рядок. В обох застосунках засоби керування темою та стилями застосовують вибраний колір чи варіант одразу.

Кожна зміна — один крок скасування, спільний із текстовим редактором: ⌘Z з будь-якого боку скасує її.

## Як змінюється текст

Текст залишається першоджерелом, а панель змінює в ньому якомога менше:

- змінене значення переписується на місці, тож коментарі та вирівнювання рядка зберігаються;
- рядок видаленого ключа зникає; однорядковий блок, наприклад `style tag "external" { fill "#999999" dashed true }`, залишається однорядковим;
- нові ключі додаються в кінець свого блока, нові блоки — після інших блоків стилів (або над `model`, якщо блоків стилів ще немає), нова інструкція вибору теми — після оголошень тем;
- початковий порядок запису зберігається незалежно від порядку введення в полі.

Наприклад, коли ви змінюєте заливку контейнера на панелі, блок

```
style container {
  fill "#438dd5"   // brand blue
  stroke "#3c7fc0"
}
```

перетворюється на

```
style container {
  fill "#1168bd"   // brand blue
  stroke "#3c7fc0"
}
```

## Корисно знати

- **`true` і `false`** зберігаються як `1` і `0`, як у draw.io, тому в полях `dashed true` відображається як `dashed=1`. Незмінений запис зберігає початкове слово.
- **Значення** в полях стилів не можуть містити `;`, як і у вбудованих стилях. Для ключів теми відведено по одному рядку, тому їхні значення можуть містити `;`.
- **Кілька блоків з одним селектором** показуються як кілька рядків; якщо вони задають той самий ключ, перемагає пізніший блок.
- **Тема з двома блоками `node` для одного виду** виводиться заново при зміні кольорів цього виду на панелі, бо панель не може визначити, який саме блок ви мали на увазі.
- **Перейменування чи видалення оголошення теми** виконується в тексті; панель редагує тему, з якою малюється подання.
- **Де це доступно:** у вебзастосунку та застосунках для macOS і Linux (GTK). У застосунку для Windows інспектора поки немає.
