# Малювання з агентами ШІ

Діаграми DiaDraw — це звичайний текст, тож агент ШІ пише їх так само легко, як код. Агент записує файл `.draw`, перевіряє його, рендерить, переглядає зображення й виправляє те, що читається погано, — тобто проходить той самий цикл, що й людина в застосунку. Цей цикл спрощують дві складові, які добре працюють разом:

- **Сервер MCP**, `diadraw mcp`: надає будь-якому агентові, що підтримує [Model Context Protocol](https://modelcontextprotocol.io) (Claude Code, Claude Desktop та інші), інструменти для перевірки, рендерингу й імпорту діаграм. Рендеринг повертає зображення, тож агент бачить намальовану діаграму.
- **Навичка (skill) для Claude Code**: навчає Claude Code мови та циклу «перевір, відрендер, подивися, виправ». Установіть її командами `/plugin marketplace add mykulyak/diadraw` і `/plugin install diadraw@diadraw` (див. [plugins/diadraw/README.md](../../plugins/diadraw/README.md)).

## Що вміє агент

| Інструмент  | Що робить                                                                                                                |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| `check`     | Повідомляє про помилки й попередження у форматі `рядок:стовпець: важливість: повідомлення` і перелічує подання документа |
| `render`    | Малює одне подання й повертає його як зображення PNG (або SVG); може також записати файл `.svg`, `.png` чи `.pdf`        |
| `format`    | Повертає документ у канонічному вигляді або перезаписує файл                                                             |
| `import`    | Перетворює діаграми Mermaid, PlantUML, Structurizr, draw.io і BPMN на документ DiaDraw                                   |
| `reference` | Перелічує види елементів, фігури, теми, розкладки й бібліотеки або види й фігури однієї бібліотеки (`library: "c4"`)     |
| `examples`  | Перелічує [приклади діаграм](examples.md) і повертає будь-який із них, щоб агент міг почати зі схожого                   |

Кожен інструмент приймає документ як `source` (його текст) або як `path` (файл). Краще працювати з файлами у вашому проєкті: тоді діаграма зберігається в системі контролю версій, як і все інше. Бібліотеки знаходяться офлайн, як і в командному рядку: вбудовані, набори трафаретів draw.io та все, що `diadraw lib install` поклав у кеш.

## Налаштування

Сервер входить до інструмента командного рядка `diadraw`. Він є в пакетах для Linux і Windows; в інших випадках зберіть його з репозиторію (див. [src/README.md](../../src/README.md)):

```sh
cmake --preset release && cmake --build --preset release
# виконуваний файл: ../diadraw-build/release/diadraw
```

Потім вкажіть агентові, де він лежить. Якщо його немає в `PATH`, указуйте повний шлях.

### Claude Code

```sh
claude mcp add diadraw -- /шлях/до/diadraw mcp
```

Так сервер додається до поточного проєкту лише для вас. Додайте `--scope user`, щоб він був у кожному проєкті, або `--scope project`, щоб записати його у файл `.mcp.json` проєкту й поділитися з усіма, хто над ним працює. Щоб перевірити з’єднання, введіть `/mcp` у Claude Code.

### Claude Desktop

Відкрийте **Settings › Developer › Edit Config** і додайте DiaDraw до `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "diadraw": {
      "command": "/шлях/до/diadraw",
      "args": ["mcp"]
    }
  }
}
```

Перезапустіть Claude Desktop. Claude Desktop запускає сервер поза будь-яким проєктом, тож попросіть його вказувати повні шляхи до файлів, які він читає й записує.

### Інші агенти

Будь-який клієнт MCP може запускати `diadraw mcp` як локальний сервер (stdio): він читає по одному повідомленню JSON-RPC на рядок зі стандартного входу й відповідає на стандартний вихід.

## Як попросити діаграму

Попросіть звичайними словами й скажіть, куди покласти файл, наприклад:

> Намалюй контейнери нашого сервісу оформлення замовлень як діаграму C4 у `docs/checkout.draw`, відрендер її в `docs/checkout.svg` і перевір, чи зображення добре читається.

Агент записує файл, запускає `check`, доки не зникнуть помилки, потім викликає `render` і переглядає зображення. Якщо прямокутники накладаються або потік іде не в той бік, він змінює подання, наприклад `layout layered direction right` чи `pin db below api`, і рендерить знову. Потім ви можете відкрити той самий файл у будь-якому застосунку DiaDraw і далі редагувати його вручну або на полотні.
