# Повідомлення про помилки та відгуки

У кожному застосунку DiaDraw на панелі інструментів завжди видно кнопку **Give Feedback**: одним клацанням можна відкрити форму, щоб поділитися ідеями, побажаннями чи підказати, що можна спростити. Команда **Report a Bug…** призначена для випадків, коли щось працює не так, як мало б.

| Застосунок | Give Feedback | Report a Bug |
| --- | --- | --- |
| macOS | праворуч на панелі інструментів | меню Help |
| Linux (GTK) | на панелі заголовка біля головного меню | головне меню (☰) угорі праворуч |
| Windows | праворуч на панелі інструментів | меню Help |
| Веб і настільний застосунок (Tauri) | праворуч на панелі інструментів | поруч із Give feedback |

На сайті також є посилання Give feedback угорі кожної сторінки.

Кожна команда відкриває в браузері нове звернення у трекері DiaDraw на GitHub з уже заповненими відомостями про застосунок, версію DiaDraw і вашу систему. Для надсилання потрібен обліковий запис GitHub. Жодні дані не надсилаються із застосунку, доки ви не натиснете **Create** на GitHub, а ваша діаграма ніколи не додається автоматично. Якщо проблема залежить від діаграми, вставте у форму найменший фрагмент тексту `.draw`, який її відтворює, і вилучіть усе, чим не хочете ділитися.
