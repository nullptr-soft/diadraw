# Zgłaszanie błędów i przekazywanie opinii

W każdej aplikacji DiaDraw na pasku narzędzi jest zawsze widoczny przycisk **Give Feedback**. Jednym kliknięciem otworzysz formularz, w którym możesz podzielić się pomysłem, napisać, czego Ci brakuje, lub wskazać, co mogłoby być prostsze. Jeśli coś nie działa tak, jak powinno, wybierz **Report a Bug…**.

| Aplikacja | Przekazywanie opinii (Give Feedback) | Zgłaszanie błędów (Report a Bug) |
| --- | --- | --- |
| macOS | Na prawym końcu paska narzędzi | W menu Help |
| Linux (GTK) | Na pasku nagłówka, obok menu głównego | W menu głównym (☰) w prawym górnym rogu |
| Windows | Na prawym końcu paska narzędzi | W menu Help |
| Internetowa i komputerowa (Tauri) | Na prawym końcu paska narzędzi | Obok przycisku Give feedback |

W witrynie opcję Give feedback znajdziesz również u góry każdej strony.

Każda z tych opcji otwiera w przeglądarce formularz nowego zgłoszenia w repozytorium DiaDraw na GitHubie. Nazwa aplikacji, wersja DiaDraw i informacje o systemie są już wpisane. Do wysłania zgłoszenia potrzebujesz konta na GitHubie. Nic nie opuszcza aplikacji, dopóki nie naciśniesz **Create** na GitHubie. Twój diagram nigdy nie jest dołączany: jeśli problem zależy od diagramu, wklej do formularza jak najkrótszy fragment tekstu `.draw`, który go pokazuje. Pomiń wszystko, czego nie chcesz udostępniać.
